Einstellungen

Export/Import

Export und Import benötigen eine Internetverbindung.

JSON exportieren

Produkte einschließlich Packungspreisen, Bestandspositionen, Bestellliste, Lagerorte und Fächer sichern. Bilder, Bildverweise und Gerätezugänge werden nicht exportiert. Während des Exports bitte keine Daten ändern.

Alternativ eine ZIP-Sicherung mit allen Produktbildern, Beschriftungen und ihrer Reihenfolge erstellen (maximal 100 MB und 1999 Bilder). Bilder werden unverändert als WebP übernommen. Gerätezugänge bleiben ausgeschlossen.

JSON oder ZIP importieren

Ergänzt das verbundene Inventar, ohne vorhandene Daten zu ändern oder zu löschen. Bereits importierte Datensätze werden übersprungen; gleiche Orts- und Fachnamen werden wiederverwendet. Produkte werden anhand ihrer ID erkannt, nicht anhand von Name oder Produktnummer.

Bitte eine Exportdatei auswählen.

Ein Import läuft schrittweise. Bei einem Fehler bleiben bereits ergänzte Daten erhalten. Dieselbe Datei kann erneut importiert werden, ohne diese Daten zu duplizieren. Bestands- und Bestellmengen werden weder addiert noch abgeglichen; bereits auf der Bestellliste vorhandene Produkte werden übersprungen. Bitte währenddessen keine Daten auf anderen Geräten ändern.

ZIP-Dateien werden vollständig geprüft, bevor Daten geschrieben werden. Anschließend werden Produkte und Bestand ergänzt, danach die Bilder. Bestehende Bilder bleiben unverändert. Nur unveränderte Eisfach-ZIP-Sicherungen werden unterstützt; bitte nicht neu komprimieren.
